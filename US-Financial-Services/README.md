# 📊 Sigma Computing Projects

A collection of interactive business intelligence dashboards
built with Sigma Computing — covering financial analytics,
loan portfolio management, and operational reporting across
multiple industries and business functions.

Each project is built end-to-end from raw data, with custom
data models and interactive filter architecture designed for
executive and operational use cases.

---

## 🗂️ Projects

### 1. US Financial Services Portfolio
> Sigma Computing · Loan Portfolio · Branch Performance · 2024

A comprehensive financial analytics dashboard tracking 50
active loans across six US regional bank branches — providing
real-time visibility into portfolio health, NPL ratios, credit
risk distribution, and branch-level profitability.
